    Como obter o token de acesso

    A API oficial só permite ler comentários de publicações da sua própria conta profissional (Comercial ou Criador de conteúdo). Para publicações de terceiros, use “Importar lista”.

    Opção A — API do Instagram (mais simples)

    1. Acesse developers.facebook.com/apps e crie um app do tipo Empresa.
    2. Adicione o produto Instagram → “API com login do Instagram”.
    3. Em Gerar tokens de acesso, adicione sua conta profissional e gere o token.
    4. Permissões: instagram_business_basic e instagram_business_manage_comments.
    5. Cole aqui o token (começa com IG). Ele vale 60 dias.

    Opção B — API do Facebook (conta vinculada a uma Página)

    1. Vincule a conta profissional do Instagram a uma Página do Facebook.
    2. No Explorador da Graph API, selecione seu app.
    3. Permissões: instagram_basic, instagram_manage_comments, pages_show_list, pages_read_engagement.
    4. Gere o token de usuário (começa com EAA) e cole aqui.

    O Sorteador não é afiliado ao Instagram nem à Meta. Veja a Política de Privacidade e os Termos de Uso.

    Sem limite de comentários: o app percorre todas as páginas da API. Se o Instagram aplicar limite de requisições, o carregamento espera e continua sozinho — e pode ser pausado e retomado depois, mesmo fechando o navegador.
